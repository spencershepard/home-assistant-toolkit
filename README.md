# Home Assistant Toolkit

This repository contains various tools and components for enhancing voice interaction capabilities in Home Assistant.
Including hotword detection, speech-to-text, and webhook integration.

## Components

- **stt/**: Full bi-directional TTS and response processing with Whisper, Porcupine hotword detection, and webhook communication
- **canvas-mcp/**: MCP server for canvas integration - a live html interface for your agent to use - I integrate the canvas into Home Assitant dashboards
